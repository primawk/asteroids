# asteroids
- Developed a 2D Asteroids arcade game using Python and Pygame, applying object-oriented programming principles to structure game entities and mechanics.
- Designed reusable classes for game objects, including the player, asteroids, projectiles, and game logic, encapsulating their attributes and behaviors.
- Implemented object interactions, collision detection, player movement, and projectile mechanics through modular class-based architecture.
- Applied separation of responsibilities to improve code organization, maintainability, and extensibility.
